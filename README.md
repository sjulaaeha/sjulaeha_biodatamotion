# sjulaeha_biodatamotion
Biodata Motion adalah aplikasi portofolio pribadi yang dirancang khusus untuk pelajar dan mahasiswa agar lebih mudah menampilkan identitas, aktivitas harian, serta perjalanan pendidikan dalam satu tampilan yang elegan dan interaktif.  Dengan tampilan yang simpel, hangat, dan penuh motivasi, Biodata Motion mendukungmu tetap produktif setiap hari!
